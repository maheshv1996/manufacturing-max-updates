## Decisions Taken

- Store files as `Bytes` in PostgreSQL (low deps, atomic backups). Require audit logs for every DB mutation.
- Default to `BATCH` tracking and `requireMillCerts: OFF` for easier onboarding. Use 150ms globally for transitions.
- **P-series enforcement is on-read** (auto-expire permits, auto-suspend access, auto-close cycles) so no cron is needed for safety gates; every approval/override/block carries a written reason into the audit trail; worker actors get 403 where managers get 200 (verified per feature).
- Department tiles live in `src/lib/departments.ts` as the single source of truth (gateway + sidebar rail + import pick up automatically); all printable reports are white-paper routes under /reports.
- SERIAL ECO effectivity without a scanned serial defaults to PRE-ECO (effectivityPending flag). R&D prototype projects bypass ECO gates.
- Calibration status ALWAYS computed live from `expiresAt` (stored `status` is a denormalized snapshot); tool crib `effectiveLocation()` returns QUARANTINE for expired instruments.
- Corporate registers are generic: `/api/register/[entity]` + `DynamicRegister` power all registers - new registers are config, not code.
- Onboarding wizard admin is created with `isOwner: true`; onboarding sample loader is compact (NOT the 3000-line seed - that stays CLI/desktop-only).
- Desktop edition defaults to file SQLite (backup = file copy); bundled Postgres supported via POSTGRES_BIN_DIR.
- Embedded-PG backups are logical-first (pg_dump -Fc, zero downtime, keep-30, rotated), physical pgdata copy is the fallback when the dump binary is not shipped.
- Unused-code hygiene is enforced at compile time (noUnusedLocals/Parameters); when a bulk cleanup tool is used, always re-run full tsc AND scan git diff for silent literal/template damage (`${name}` in strings etc.).

## Gotchas & Warnings

- **Windows embedded-PG postmaster can wedge with error 487** (autovacuum 0xC0000142 → "could not reserve shared memory region … error code 487"): the postmaster keeps LISTENING but every new backend times out and `pg_ctl stop` hangs. Recovery: force-kill the postmaster (`Stop-Process -Force`, or `taskkill`), then `pg_ctl start` — Postgres WAL-recovery comes back clean ("redo is not required"). The launcher's dbWatchdog restarts a crashed postmaster, but a wedged-but-listening one is invisible to it.
- **Silent NSIS installs reuse the REGISTERED install dir**: `ManufacturingMax-Setup-X.exe /S /D=<dir>` to a scratch dir still uninstalls the previously registered install (same app GUID) and re-installs into `$INSTDIR` — the old registered copy disappears (data survives — it lives outside the install). To relocate, uninstall first, then install.
- **Vercel Timeout:** free/hobby limits enforce 10s max execution; set `maxDuration` appropriately.
- **Not Authorized errors:** CLI/SDK "Not authorized" usually needs re-login or quota refresh.
- **Prisma Edge Cases:** always double-check includes returning `null` vs empty arrays; multi-field `orderBy` must be an array.
- **proxy.ts is Node-runtime** (Next 16 default): any change must keep Edge bundling safe (no static imports of Node-only code in public paths).
